CreateLuaEvent

Registers a global timed event.

When the passed function is called, the parameters (eventId, delay, repeats) are passed to it.

Repeats will decrease on each call if the event does not repeat indefinitely

Synopsis
eventId = GlobalMethods:CreateLuaEvent(function, delay)
eventId = GlobalMethods:CreateLuaEvent(function, delaytable)
eventId = GlobalMethods:CreateLuaEvent(function, delay, repeats)
eventId = GlobalMethods:CreateLuaEvent(function, delaytable, repeats)
Parameters
function
function
function to trigger when the time has passed
uint32
delay
set time in milliseconds for the event to trigger
table
delaytable
a table {min, max} containing the minimum and maximum delay time
uint32
repeats
default: 1
how many times for the event to repeat, 0 is infinite
Returns
int
eventId
unique ID for the timed event used to cancel it or nil
